Rehber

Sorun giderme

Başlarken

  1. Herhangi bir programda Türkçe metni seçin.
  2. Ctrl+Shift+Space'e basın.
  3. Seçili metin İngilizcesiyle değişir.
Simge saatin yanındaki ^ menüsünde olabilir; görev çubuğuna sürükleyebilirsiniz.

Yerel mi, bulut mu?

  • Yerel: internetsiz çalışır, metin bilgisayardan çıkmaz. Kısa cümlelerde iyi, uzun ve dağınık metinde zayıf.
  • Bulut: çeviri kalitesi daha yüksek; metin seçtiğiniz servise gider. Gemini'nin ücretsiz katmanı çoğu kişiye yeter.
Kararsızsanız: Bulut + "çalışmazsa yerele geç". Bulut bir sorun verirse bkz. API anahtarı hatası / kota doldu.

Ücretsiz Gemini anahtarı

  1. Google AI Studio'yu açın: aistudio.google.com/apikey
  2. Google hesabınızla girin, Create API key'e basın.
  3. Anahtarı kopyalayın, tr2en'de Çeviri → API anahtarı alanına yapıştırın.
  4. Bağlantıyı dene'ye basın; "Çalışıyor" görmelisiniz.
Anahtar Windows Kimlik Yöneticisi'nde şifreli saklanır. Hata alıyorsanız bkz. API anahtarı hatası / kota doldu.

OpenAI · DeepSeek · OpenRouter

Bunlar ücretli servislerdir (kullandıkça ödenir). Servisin sitesinde hesap açın, "API keys" bölümünden anahtar oluşturun ve tr2en'e yapıştırın. Model adını servisin model listesinden kopyalayın.

Model adı nedir?

Servislerin birden çok yapay zekâ modeli vardır; çeviriyi hangisinin yapacağını model adı belirler. Model alanı bir açılır listedir: önerilen modeller listelenir; listede olmayan bir modeli kullanmak için "Kendin ekle…" seçip adı elle yazın (ör. gpt-4o-mini). Küçük ve hızlı modeller çeviri için yeterlidir. Yavaş kalıyorsa bkz. Çeviri yavaş.

Yerel model ekleme

Ollama (en kolay):
  1. ollama.com'dan Ollama'yı kurun.
  2. Bir model indirin, ör. ollama pull qwen3:1.7b.
  3. tr2en'de Çeviri → Yerel → Model ekle → Ollama; listeden modeli seçin.
LM Studio: programı kurun, içinden bir model indirip "Local Server"ı başlatın, sonra tr2en'de LM Studio'yu seçin.
Model klasörü: CTranslate2 biçiminde bir çeviri modeliniz varsa klasörünü seçin (ileri düzey).
Büyük modeller daha çok bellek ister ve yavaş olabilir. Bağlanamıyorsanız bkz. Ollama'ya bağlanamıyor; çeviri yavaşsa bkz. Çeviri yavaş.

Kısayol ve çakışmalar

Önerilen kısayol Ctrl+Shift+Space'tir; başka programlarla çakışmaz. Kendi kısayolunuzu seçerseniz: metin seçiliyken tr2en çevirir, seçim yokken tuşu programa geri gönderir. Ctrl+C/V/X/Z/Y/A/S, Alt+F4 ve Ctrl+Alt kullanılamaz. Hiçbir şey olmuyorsa bkz. Kısayola basınca bir şey olmuyor.

"Bilgisayarınızı korudu" uyarısı

tr2en henüz dijital imzalı olmadığı için Windows bu uyarıyı gösterebilir. Ek bilgi → Yine de çalıştır'a basın. Dosyanın doğruluğunu sürüm sayfasındaki .sha256 ile kontrol edebilirsiniz. Antivirüs uyarısı alıyorsanız bkz. Antivirüs uyarı verdi.

Gizlilik

Çevrilen metin hiçbir yere kaydedilmez. Metin yalnızca seçtiğiniz servise gider; yerel modelde bilgisayardan çıkmaz. tr2en'in kendiliğinden yaptığı tek bağlantı dahili modelin ilk indirilmesidir. Telemetri yoktur. Güncelleme denetimi yalnızca siz "Güncellemeleri kontrol et"e bastığınızda yapılır (GitHub'a sorulur).

Kısayola basınca bir şey olmuyor

  1. Çalışıyor mu: Çevir sayfasının altındaki durum satırında "Çalışıyor" yazmalı; görev çubuğunda da tr2en simgesi görünmelidir.
  2. Duraklatılmış mı: durum satırına basın ya da tepsi menüsündeki Etkin işaretini açın.
  3. Metin seçili mi: kısayol yalnızca seçili metni çevirir; önce Türkçe metni seçin.
  4. Çakışma var mı: Kısayol sayfasından başka bir tuş birleşimi seçip "Kaydet" deyin.
  5. Yönetici olarak çalışan bir programda deniyorsanız bkz. Yönetici olarak çalışan programlar.

Çeviri yapıştırılmadı

  1. Bazı programlar dışarıdan yapıştırmayı engeller; bu programlarda çeviri metni yapıştırılamaz.
  2. Çeviriyi tepsi menüsünden Son çeviriyi göster ile alın.
  3. Pano, işlem bitince tr2en tarafından eski hâline geri yüklenir.

Yönetici olarak çalışan programlar

Windows, normal yetkili bir programın yönetici yetkili bir pencereye tuş göndermesine izin vermez. Bu yüzden yönetici olarak çalışan programlarda tr2en çalışmaz.

  1. Yönetici olarak çalışan programı normal kullanıcıyla yeniden başlatıp tekrar deneyin.
  2. Yönetici olmadan çalışan başka bir programda kısayola basmayı deneyin.

Terminalde çalışmıyor

Bu sürümde terminalde (PowerShell, cmd) seçili metin değiştirilemez.

  1. Çevirmek istediğiniz metni kopyalayın.
  2. Çevir sayfasındaki kutuya yapıştırın ve Çevir deyin.
  3. Sonucu Kopyala ile alın.

API anahtarı hatası / kota doldu

  1. Anahtarı yeniden kaydedin: Çeviri → API anahtarı alanına yapıştırıp Bağlantıyı dene'ye basın.
  2. Ücretsiz katmanda geçici kullanım sınırları olabilir; biraz sonra yeniden deneyin.
  3. "Bulut çalışmazsa yerele geç" açıkken çeviri yerel modelle devam eder.

Ollama'ya bağlanamıyor

  1. Ollama açık mı: tepside Ollama simgesi görünmeli.
  2. Adres doğru mu: http://localhost:11434/v1 olmalı.
  3. Model indirildi mi: ollama pull <model> ile indirin.
  4. Model listesi: Listele düğmesiyle kontrol edin.

Dahili model inmedi

  1. İlk açılışta internet gerekir; model indirilmeden çeviri yapılamaz.
  2. Güvenlik duvarı huggingface.co adresini engelliyor olabilir.
  3. tr2en'i yeniden başlatınca indirme yeniden denenir.

Antivirüs uyarı verdi

tr2en kısayolu tanımak için klavye kancası kullanır; bazı antivirüsler bunu şüpheli bulabilir.

  1. Kod açıktır ve MIT lisanslıdır: GitHub deposundan inceleyebilirsiniz.
  2. Dosyayı sürüm sayfasındaki .sha256 dosyasıyla doğrulayın.

Çeviri yavaş

  1. Yerel büyük modeller yavaştır; daha küçük bir model seçin.
  2. Bulut servisini deneyin; bulut modelleri genelde çok daha hızlıdır.
Model hızına ilişkin uyarıyı Çeviri → Yerel sayfasında görebilirsiniz.

tr2en'e hoş geldiniz

Herhangi bir programda Türkçe metni seçip kısayola basın; İngilizcesiyle değişir.

Bulutta metin seçtiğiniz servise (varsayılan Google Gemini) gönderilir; ücretsiz katmanda Google bu metinleri ürünlerini geliştirmek için kullanabilir. Hassas metinlerde Yerel'i seçin.

Ücretsiz Gemini anahtarı

  • Google AI Studio'da "Create API key" ile ücretsiz bir anahtar oluşturun.
  • Anahtarı aşağıya yapıştırıp "Kaydet" ile saklayın.
  • "Bağlantıyı dene" ile çeviriyi doğrulayın.

Yerel model

Dahili model ilk kullanımda bir kez indirilir; sonra internetsiz çalışır.

Ollama / LM Studio eklemek için Ayarlar → Çeviri → Yerel.
