Rehber

Başlarken

  1. Herhangi bir programda Türkçe metni seçin.
  2. Ctrl+Shift+Space'e basın.
  3. Seçili metin İngilizcesiyle değişir.
Simge saatin yanındaki ^ menüsünde olabilir; görev çubuğuna sürükleyebilirsiniz.

Yerel mi, bulut mu?

  • Yerel: internetsiz çalışır, metin bilgisayardan çıkmaz. Kısa cümlelerde iyi, uzun ve dağınık metinde zayıf.
  • Bulut: çeviri kalitesi daha yüksek; metin seçtiğiniz servise gider. Gemini'nin ücretsiz katmanı çoğu kişiye yeter.
Kararsızsanız: Bulut + "çalışmazsa yerele geç".

Ücretsiz Gemini anahtarı

  1. Google AI Studio'yu açın: aistudio.google.com/apikey
  2. Google hesabınızla girin, Create API key'e basın.
  3. Anahtarı kopyalayın, tr2en'de Çeviri → API anahtarı alanına yapıştırın.
  4. Bağlantıyı dene'ye basın; "Çalışıyor" görmelisiniz.
Anahtar Windows Kimlik Yöneticisi'nde şifreli saklanır.

OpenAI · DeepSeek · OpenRouter

Bunlar ücretli servislerdir (kullandıkça ödenir). Servisin sitesinde hesap açın, "API keys" bölümünden anahtar oluşturun ve tr2en'e yapıştırın. Model adını servisin model listesinden kopyalayın.

Model adı nedir?

Servislerin birden çok yapay zekâ modeli vardır; çeviriyi hangisinin yapacağını model adı belirler. Gemini'de hazır gelir. Diğerlerinde servisin "Models" sayfasındaki adı (ör. gpt-4o-mini) aynen yazın. Küçük ve hızlı modeller çeviri için yeterlidir.

Yerel model ekleme

Ollama (en kolay):
  1. ollama.com'dan Ollama'yı kurun.
  2. Bir model indirin, ör. ollama pull qwen3:1.7b.
  3. tr2en'de Çeviri → Yerel → Model ekle → Ollama; listeden modeli seçin.
LM Studio: programı kurun, içinden bir model indirip "Local Server"ı başlatın, sonra tr2en'de LM Studio'yu seçin.
Model klasörü: CTranslate2 biçiminde bir çeviri modeliniz varsa klasörünü seçin (ileri düzey).
Büyük modeller daha çok bellek ister ve yavaş olabilir.

Kısayol ve çakışmalar

Önerilen kısayol Ctrl+Shift+Space'tir; başka programlarla çakışmaz. Kendi kısayolunuzu seçerseniz: metin seçiliyken tr2en çevirir, seçim yokken tuşu programa geri gönderir. Ctrl+C/V/X/Z/Y/A/S, Alt+F4 ve Ctrl+Alt kullanılamaz.

"Bilgisayarınızı korudu" uyarısı

tr2en henüz dijital imzalı olmadığı için Windows bu uyarıyı gösterebilir. Ek bilgi → Yine de çalıştır'a basın. Dosyanın doğruluğunu sürüm sayfasındaki .sha256 ile kontrol edebilirsiniz.

Gizlilik

Çevrilen metin hiçbir yere kaydedilmez. Metin yalnızca seçtiğiniz servise gider; yerel modelde bilgisayardan çıkmaz. tr2en'in kendiliğinden yaptığı tek bağlantı dahili modelin ilk indirilmesidir. Telemetri yoktur.
